мэдэгддэг вэб. Зөвхөн сигнал өгнө; захиалга илгээхгүй, брокертой холбогдохгүй.

Бүрэн төлөвлөгөө: [docs/PLAN.md](docs/PLAN.md). Кодлох дүрэм: [CLAUDE.md](CLAUDE.md).

## Вэб самбарыг ажиллуулах

Самбар таны компьютер дээр ажиллана (`127.0.0.1`). Интернэтээр, утаснаас үзэх нь 9-р шатанд орно.

1. Нууц үгээ тохируулна (нэг удаа). Нууц үг хаана ч хадгалагдахгүй, зөвхөн хэш нь `.env`-д бичигдэнэ:

   ```
   .venv\Scripts\python -m backend.scripts.set_password
   ```

2. Серверийг асаана:

   ```
   .venv\Scripts\python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
   ```

3. Хөтөч дээр <http://127.0.0.1:8000> нээж нэвтэрнэ. Дээд талын «Мэдэгдэл асаах» товчийг дарвал
   шинэ сигнал, ханш тасрах үед компьютер дээр мэдэгдэл гарч, дуут дохио өгнө (хуудас нээлттэй үед).

Юу хийдэг вэ:

- Binance-ийн XAUUSDT ханшийг 2 секунд тутам авч, хуудас руу шууд түлхэнэ. Лаа хаагдахад 2–4 секундын
  дотор дүрэм, шүүлтүүрийг нэг удаа тооцно.
- Шүүлтүүр: H1 чиг, давхардал, ханшийн хоцрогдол, зах зээлийн цаг (ойролцоо хуваарь). Мэдээний шүүлтүүр
  хараахан байхгүй.
- Ханш 60 секунд ирэхгүй бол сигнал зогсож, хуудсанд «Ханш тасарсан» гэж гарна. Хуучин үнээр сигнал гаргахгүй.
- Сигнал бүр «туршилтын», B зэрэглэлтэй: backtest хийгдээгүй.
- Сервер унтарвал сигнал, мэдэгдэл зогсоно. Түүх дахин асаахад сүүлийн 48 цагийн лаанаас сэргээгдэнэ.

### Таамаг (дараагийн 60 минут)

График дээрх ягаан тасархай шугам нь M15-ийн дараагийн 4 лааны хаалтын таамаг юм. Шугамын цэгүүд нь
лаа тус бүрийн таамагласан хаалт, төгсгөлд нь «Таамаг» гэж бичсэн байна. Энэ нь сигнал биш,
сигналыг үүсгэхгүй, өөрчлөхгүй, хаахгүй. Шугам үнийн тэнхлэгийн хэмжээсийг өөрчлөхгүй, график хажуу
тийш үсрэхгүй. Загварыг сургахдаа:

```
.venv\Scripts\python -m backend.scripts.train_forecast
```

Скрипт Binance-ээс XAUUSDT-ийн M15 түүхийг бүтнээр нь татаж (нэг минут орчим), загварыг «урагш алхах»
аргаар шалгаад, үр дүнг `data/forecast_model.json`-д бичнэ. Дараа нь серверийг дахин асаана. Файл
байхгүй бол таамаг харагдахгүй.

Тоонууд юу гэсэн үг вэ:

- **Алдаа (mae)**: 60 минутын дараах бодит хаалтаас таамаг дунджаар хэдэн доллараар зөрсөн. Хажууд нь
  «үнэ байрандаа үлдэнэ» гэсэн хамгийн энгийн таамгийн алдаа (baseline_mae) байна.
- **Чиг таасан хувь (hit_rate)**: загвар «өснө» эсвэл «буурна» гэж хэлсэн тохиолдлуудын хэд нь зөв байсан.
  Магадлал 50%-д ойр үед загвар чиг хэлэхгүй («тодорхойгүй»). Хуудас энэ хувийг 50%-тай биш, «тэр
  бүгдэд үргэлж өсөх (эсвэл буурах) гэж хэлсэн бол хэд нь зөв байх байсан» гэсэн тоотой зэрэгцүүлж
  харуулна. Бүртгэлд чиг хэлсэн тохиолдол байхгүй үед загвар «өсөх», «буурах» гэвэл хуудас тэр үгийг
  «туршилтаар шалгагдаагүй» гэж анхааруулна.
- **Зурвас (coverage)**: бодит хаалтын хэдэн хувь нь зурвасын дотор унасан (80% орчим байх ёстой).
- **better_than_baseline**: загвар энгийн таамгаас тоогоор батлагдахуйц сайн байсан эсэх.

Бүртгэлд зөвхөн брокерын зах зээл нээлттэй байх магадлалтай цагт хийсэн таамгийг, мөн эцсийн загварын
сургалтын мөрийн дор хаяж талыг харсан загваруудын таамгийг тоолно (scope: open_market). Чиглэлийн үг
шугамтайгаа зөрвөл «тодорхойгүй» гэж гарна.

2026-11-22-ны сургалтын үр дүн (33,255 лаа; зах зээл нээлттэй цагийн 10,212 таамаг шалгасан,
2026-06-18-аас 2026-11-20): алдаа 8.055, энгийн таамгийнх 8.051; зурвас 80.6%. Шалгалтад орсон
загварууд энэ хугацаанд нэг ч удаа чиг хэлээгүй (0 удаа): өсөх магадлал нь 49.4%–51.7%-ийн хооронд л
байсан. Тиймээс чиг таасан хувь гэж байхгүй. **Дүгнэлт: загвар «үнэ байрандаа үлдэнэ» гэснээс илүү
биш.** Иймээс шугамыг зөвхөн мэдээллийн зорилгоор харуулна, түүнд тулгуурлан арилжаа хийж болохгүй.
Мэдээний өгөгдөл төсөлд хараахан байхгүй тул загварт ороогүй.

Анхаар: дэлгэцэд харагдаж буй эцсийн загвар шалгалтад орсон загваруудаас арай өөр тохиргоотой сурсан
(загвар бүр шахалтын хүчээ өөрөө сонгодог). Тэр хааяа «өсөх», «буурах» гэж хэлдэг: сурсан 32,052
лааныхаа 545-д нь (1.7% орчим). Ийм үгийг шалгалт нэг ч удаа хэмжээгүй. Өөрөөр хэлбэл дэлгэц дээрх
чиглэлийн үгийн ард ямар ч бүртгэл байхгүй: зөв ч гэж, буруу ч гэж батлагдаагүй. Сургалтын скрипт
одоо энэ тоог өөрөө хэвлэдэг.

И-мэйл мэдэгдэл авах бол `.env`-д SMTP тохиргоог бөглөнө (`.env.example`-д тайлбар бий; Gmail бол
апп-ын нууц үг хэрэгтэй). Нууц үгээ чатад бичихгүй, зөвхөн `.env`-д хийнэ. Техникийн тайлбар:
[docs/WEB.md](docs/WEB.md).

## 3-р шат: ханшийн эх үүсвэрийг шалгах

Анхдагч эх үүсвэр нь Binance XAUUSDT (түлхүүр шаардахгүй). Twelve Data-г
хэрэглэх бол `.env`-д `TRADEPILOT_TWELVEDATA_API_KEY`-г бичээд, доорх команд
бүрд `--source twelvedata` гэж нэмнэ. Тэр үед цуглуулгын файл нь
`data/collect_twelvedata_M15.csv` болно.

1. **24 цаг тасралтгүй цуглуулах.** Компьютер унтахгүй, интернет тасрахгүй байх ёстой:

   ```powershell
   .venv\Scripts\python -m backend.scripts.collect_candles --hours 24
   ```

   Дуусаад (эсвэл явцад нь) шалгана:

   ```powershell
   .venv\Scripts\python -m backend.scripts.check_candles data/collect_binance_M15.csv
   ```

   Шалгалт хоёр зүйлийг хардаг: сүүлийн тасралтгүй хэсэг 24 цаг хүрсэн эсэх,
   хадгалсан лаа бүр эх үүсвэрийн одоогийн утгатай таарч байгаа эсэх. 24 цаг
   дүүрээгүй үед үр дүн `NOT YET` гэж гарна, энэ нь алдаа биш.

2. **MOT Capital MT5-тай 20 удаа харьцуулах.** Өөр өөр цагт хийнэ:

   ```powershell
   .venv\Scripts\python -m backend.scripts.compare_prices
   ```

   MT5 дээр XAUUSD-ийн bid/ask-ийг харах агшинд Enter дарж, харсан
   тоонуудаа 30 секундэд багтаан `4062.08 4062.21` гэж бичнэ. Удсан эсвэл
   энэ хооронд ханш их хөдөлсөн бол хэмжилт хадгалагдахгүй, дахин эхэлнэ.
   Enter-ийн оронд `u` гэвэл сүүлийн хэмжилтийг устгана, `q` гэвэл зогсоно.
   Амралтын өдөр алтны зах хаалттай тул хэмжилт хийхгүй.

   Дүгнэлт гарахад 20 хэмжилт, тэдгээр нь дор хаяж 6 өөр цагт хийгдсэн байх
   шаардлагатай:

   ```powershell
   .venv\Scripts\python -m backend.scripts.compare_prices --report
   ```

Үр дүн `data/`-д хадгалагдана (git-д орохгүй).

## Сигналын дүрэм товчхон

M15-ийн сүүлийн хаагдсан лаан дээр таван нөхцөл тус бүр +1, 0, −1 оноо өгнө.
Нийлбэр ≥ +3 бол BUY, ≤ −3 бол SELL, бусад үед HOLD.

| № | Нөхцөл | +1 | −1 |
| --- | --- | --- | --- |
| 1 | Урт хугацааны чиг | Close > EMA200 | Close < EMA200 |
| 2 | Богино хугацааны чиг | EMA20 > EMA50 | EMA20 < EMA50 |
| 3 | MACD ба signal шугам | MACD > signal | MACD < signal |
| 4 | MACD ба тэг шугам | MACD > 0 | MACD < 0 |
| 5 | RSI(14) бүс | 50 < RSI < 70 | 30 < RSI < 50 |

BUY, SELL үед: орох бүс = Entry ± 0.25 × ATR, SL = 1.5 × ATR, TP = 2.0 × ATR,
хүчинтэй хугацаа 2 лаа. 300-аас цөөн хаагдсан лаатай бол сигнал гарахгүй
(`INSUFFICIENT_BARS`).

Жишээ:

```python
import pandas as pd
from backend.app.core import signal

candles = pd.read_csv("data/xauusd_m15.csv")  # time, open, high, low, close
result = signal.evaluate(candles)
print(result.to_dict())
```

## Индикаторын томьёо

- EMA: рекурсив, эхний утгаар эхэлнэ (`alpha = 2 / (period + 1)`).
- RSI, ATR: Wilder-ийн тэгшитгэл, эхний дундаж нь энгийн дундаж.
- MACD: EMA(12) − EMA(26); signal шугам нь MACD-ийн EMA(9).

Арилжааны платформын өөрийн индикатор зарим тооцоонд өөр тэгшитгэл
хэрэглэж болох тул бага зэргийн зөрүү гарвал эхлээд томьёог харьцуулна.
